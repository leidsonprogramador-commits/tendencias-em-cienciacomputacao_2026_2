**Prompts utilizados, integração implementada e ajustes realizados:**
> **SISTEMA DE LANÇAMENTO DE NOTA FISCAL**  
> CRIAMOS UM SISTEMA PARA ATENDER ALGUMAS NECESSIDADES QUE OUTROS TEM UMA CERTA DEFICIÊNCIA EM OPERAR, VISANDO UM PROCESSO MAIS RÁPIDO E PRÁTICO PARA O USUÁRIO.
> 
> **1. TELA DE LOGIN**  
> O PRIMEIRO LOGIN É PARA O ADMINISTRADOR DO SISTEMA, QUE POSSUI AUTONOMIA PARA REGISTRAR NOVOS USUÁRIOS, DEFINIR QUAIS CAMPOS ELES PODEM ACESSAR E UTILIZAR, ALÉM DE UTILIZAR TODAS AS FUNÇÕES DO SISTEMA.
> 
> **2. SISTEMA**  
> O LANÇAMENTO DE NOTAS PODERÁ SER FEITO VIA CHAVE DE ACESSO, IMPORTAÇÃO DE XML, ARQUIVO PDF OU FOTO.  
> 
> **2.1. INFORMAÇÕES OBTIDAS DA NOTA FISCAL**  
> - **2.1.1.** O SISTEMA FARÁ O CADASTRO AUTOMÁTICO DO FORNECEDOR PEGANDO AS INFORMAÇÕES DE RAZÃO SOCIAL, NOME FANTASIA (SE HOUVER), CNPJ, CEP, ENDEREÇO, TELEFONE.  
> - **2.1.2.** O SISTEMA CADASTRARÁ AUTOMATICAMENTE OS PRODUTOS DA NOTA, COM CÓDIGO, DESCRIÇÃO DO PRODUTO, NCM, UNIDADE DE MEDIDA (UND), QUANTIDADE (QTD), VALOR UNITÁRIO (V. UN.).  
> - **2.1.3.** SERÁ POSSÍVEL EDITAR AS INFORMAÇÕES OBTIDAS A PARTIR DO MOMENTO QUE FOREM OBTIDAS, COM BOTÃO DE CONFIRMAÇÃO APÓS AS ALTERAÇÕES.
> 
> **3. VERIFICAÇÕES**  
> AO LANÇAR AS INFORMAÇÕES DA NOTA, O SISTEMA DEVERÁ VERIFICAR SE O QUE FOI OBTIDO JÁ POSSUI NO SISTEMA, PODENDO INDICAR OS PRODUTOS QUE JÁ POSSUI E OS QUE SERÃO ADICIONADOS AO BANCO DE DADOS DO FORNECEDOR.  
> 
> **3.1. VERIFICAÇÃO DE INFORMAÇÃO CRUZADA**  
> O SISTEMA IRÁ VERIFICAR SE AS INFORMAÇÕES OBTIDAS DE UM FORNECEDOR SE REPETEM EM OUTRO, CRIANDO UM ALERTA PARA O USUÁRIO EDITAR O ERRO MOSTRADO.
> 
> **4. INTERFACE**  
> O SISTEMA POSSUI MENU PARA CADASTRO DE NOTA, VISUALIZAÇÃO DE FORNECEDORES, VISUALIZAÇÃO DE PRODUTOS, ADMINISTRAÇÃO DE USUÁRIOS.
